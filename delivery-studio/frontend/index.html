From a Jira card to a pull request

        
Five agents on Aetherion, each a Temporal workflow. Orchestration is the only one that talks to people; the others do one job each.

        
        

          
1 · Review
Reads everything around the card (parent, sub-tasks, links, attachments, Confluence) and scores readiness out of 5. Missing details become numbered questions.

          
2 · Answers
People answer on the card or here. Orchestration keeps every question with its answers in the card's memory, so nothing is asked twice.

          
Break down (optional)
Task Creation splits a Story into Sub-tasks or an Epic into Stories, shown first as a preview PDF. Created only when you say so; the card itself is never edited.

          
3 · Plan
Orchestration ranks the services the card touches. Planning reads their code on GitHub and writes the technical design, with a machine-readable work order inside the PDF.

          
4 · Code
Coding reads the work order, changes each service on a new branch, checks its own work and opens a draft pull request. Nothing is merged automatically.
